---
title: "Editor support"
description: "VS Code extension and Sinth IDE."
---

- **VS Code**: the official extension provides syntax highlighting, completions for elements, attributes, events, modifiers, metadata keys, your own components and sinth:ui (with auto-import), hover documentation, go to definition, snippets, error checking with `sinth check`, and commands to run the dev server, build, preview and deploy. Download `sinth-vscode-*.vsix` from the [latest release](https://github.com/Yannosay/sinth/releases/latest) and run **Extensions: Install from VSIX**.
- **Sinth IDE**: a desktop editor for Windows, macOS and Linux with Sinth highlighting, completions, inline diagnostics on save, a Problems list, an integrated terminal, one-click Run/Build/Preview/Deploy and automatic updates. Download it from [Sinth IDE releases](https://github.com/Yannosay/sinth-ide/releases/latest).
- **Other editors**: run `sinth check --json` for diagnostics in any tool.
